# DBM-CoA v3.25 — Raid and Dungeon Learning

- Encounter learning defaults on for new users in dungeon and raid instances; existing opt-outs are preserved.
- `/coalearning` reports learning status and instance type.
- `/coatimings` browses saved categorized timings, counts and stable predictions.
- Live alerts follow real enemy casts. Predicted cooldowns require repeated consistent observations; no fabricated boss timers.
- Retains Smart Archive Sync, resizable learner window, SavedVariables, and optional ElvUI/DragonUI styling.

Install every DBM-* folder from the ZIP side by side in Interface/AddOns. Back up and retain WTF/SavedVariables.

Published on the stable release channel by maintainer request. In-game Conquest Reborn validation is still pending.
